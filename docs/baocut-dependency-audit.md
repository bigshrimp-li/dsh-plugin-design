# 运行时独立化记录

当前实现已经替换旧的 vendor/support.js。可维护源码位于 src/design-runtime/，构建产物位于 dist/design-runtime/support.js。
编辑器、截图和导出通过同一个 runtimePath() 取得产物。构建脚本检查输入列表，拒绝混入该目录之外的代码。

本轮同时替换 src/check/、src/blobs.ts、src/shared.ts、工具说明和两个设计技能的派生实现。旧 vendor 构建脚本及复制的技能参考资料已删除。vendor/support.js 仅保留指向新构建产物的本地符号链接，兼容尚未重启的服务；发布包不包含该目录。

## 边界

“不需要安装 BaoCut”原本只表示无外部包调用，并不意味着没有复制代码依赖。旧审计中的“没有任何技术依赖”结论已撤回。

现在画板运行时不依赖 Claude Design、BaoCut、React 或 CDN。Harness 侧边栏仍使用宿主提供的 React 和插件接口；构建和测试仍使用通用工具。不能把本次结果表述为整个软件不依赖任何第三方平台。

兼容的文件名称、字段和 DOM 标记用于保留已有设计稿及编辑器行为。新功能应在本地协议和运行时中实现，不再回填旧 bundle。

## 功能范围

- 已实现：模板插值、条件、稳定键列表、状态、原生事件、输入控件、生命周期、ref、helmet、SVG、表格、局部组件导入、编辑源码映射、离线组件内嵌。
- 已取消隐式依赖：框架/CDN 自动加载、JSX 编译、x-import。x-import 在校验和运行时均明确报错，迁移到 dc-import 或本地自定义元素。
- 不承诺复刻：旧平台专有动画控制、未完成文件的流式执行。使用标准 CSS 动画和完整文件刷新。
- 第三方素材、用户自带脚本以及历史 Git 版本仍保留各自来源。详细依赖边界见 ../NOTICE.md。

## 验证入口

- `npm test`：静态规则、素材并发写入、编辑器事务与工具端到端。
- `npm run test:runtime`：本地运行时协议检查、交互和离线导出。
- `npm run test:browser`：现有可视化编辑回归。

维护时必须覆盖源码节点 ID、输入焦点、重复实例、组件边界和离线导出，不能只检查页面是否显示。
