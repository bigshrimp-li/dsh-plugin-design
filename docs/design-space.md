# Design 空间

Design 空间固定管理 `~/.design` 下的设计稿。每个直接子文件夹对应一份设计稿。主面板复用原编辑器，通过宿主 `SessionProvider` 与 `conversation.content` 工厂嵌入对话；右侧栏编辑器继续保留。

## 使用步骤

1. 在插件目录执行 `npm run build`，然后完全退出并重启 Harness，使 Host 路由和客户端代码生效。
2. 点击「设计区」右侧的 `＋`。插件立即创建「未命名设计稿」，打开 880 × 560 的空白画板。已有同名文件夹时追加数字。页签栏的 `＋` 使用相同逻辑。
3. 点击设计稿行打开已有设计稿。新建或打开设计稿不会自动创建会话，不会自动发送消息。外部创建的空文件夹首次打开时初始化空白画板；有效的已有画板继续使用原文件。
4. 悬停或聚焦设计稿行，点击「重命名」。原名称变为输入框。Enter 或失去焦点时保存，Escape 取消；输入法组合输入时 Enter 不提交。名称同时用于侧栏、文件夹和页签。中文和空格可用；名称为 1–120 个字符，隐藏目录名、路径分隔符和文件名禁用字符不可用。同名目录不会被覆盖。
5. 点击行末「归档」，隐藏侧栏入口并关闭该设计稿的页签。文件、会话关联和对话副本保留在原文件夹，宿主任务继续由宿主管理。
6. 在设计稿右侧点击「连接对话」，选择新对话或设计区的已有对话。新会话直接以 `~/.design` 为工作目录，无需创建或注册宿主工作区。右侧的 `＋` 可继续追加独立对话，消息和草稿由宿主保留。
7. 拖动设计稿页签调整顺序，或聚焦页签后按 `Alt + 左/右方向键`。普通方向键切换页签。关闭页签只关闭界面，保留文件和会话关联。

## 侧栏与实时更新

设计区沿用宿主字体、颜色和按钮样式，标题与工作区左对齐，不显示分区边界线。工作区和设计区可以独立折叠，折叠状态在本机保存。长列表可以滚动，账号菜单保持在底部。

设计区不提供任意目录选择或目录登记。插件每 1.5 秒重新读取 `~/.design`，窗口重新聚焦或恢复可见时也会刷新。直接子文件夹的新增、移除和重命名会自动反映到侧栏；隐藏文件夹与符号链接不进入列表。文件夹重命名保留设计稿身份、页签和会话关联，活动编辑器重新加载新路径。

当前宿主没有工作区标题扩展槽。插件对已核对的侧栏 DOM 添加受控标记和标题按钮，停用时清理。未来宿主结构变化时需要复核此兼容层。

## 文件与会话存储

| 路径 | 内容 |
|---|---|
| `~/.design/<名称>/canvas.json`、`*.dc.html` | 设计稿索引、画板及资源 |
| `~/.design/<名称>/.dsh/design-tabs.json` | 会话标识列表、默认会话、关联版本 |
| `~/.design/<名称>/.dsh/conversations/<标识摘要>.json` | 会话头及已持久化事件日志的 JSON 副本 |
| `~/.design/<名称>/.dsh/design-space.json` | 归档状态 |
| `~/.design/<名称>/.dsh-creation.json` | 创建操作凭据，用于失败重试 |
| `~/.design/.dsh/operations.json` | 创建操作与文件夹身份的映射，以及写入锁 |

宿主继续负责消息发送、模型、草稿、附件、工具审批和运行状态。关联成功时保存一份宿主对话日志副本；宿主发出会话事件后合并 750 毫秒内的更新，再读取日志并更新副本。副本只保留宿主可读取的已持久化事件，不包含未发送草稿或附件二进制。宿主仍是恢复会话的来源。

关联写入使用排他锁和版本校验，配置保存使用同目录临时文件替换并保留 `.bak`。新建、重命名、归档、关联和对话副本写入共用设计区写入锁，避免重命名期间重建旧路径。配置损坏时保留原文件并提示错误，不清空配置。

归档标记保存在原设计稿文件夹；当前没有归档列表界面。需要恢复时，先保留备份，再将该文件夹 `.dsh/design-space.json` 中的 `archived` 改为 `false`。目录刷新后设计稿重新显示。

旧版登记在 `~/.dsh/design-space/directories.json` 的外部目录不再加载，也不会被自动移动。新逻辑仅管理 `~/.design`。已有外部设计稿可复制到该目录作为新的设计稿；旧工作区会话仍由宿主管理，不自动迁移。

## 对话命名与布局

对话命名使用 DSH 的全局首轮模型命名流程。插件通过宿主会话目录订阅标题，标题生成或宿主重命名后立即同步显示。连接旧对话时也读取同一标题；无标题或旧的 session 标识标题显示为「未命名对话」。空的当前对话仍由顶部 `＋` 表示。

画布右侧保留会话页签和 `＋`。右上角支持分栏、全屏、收起／打开对话侧栏。分栏显示同一设计稿的两个独立会话，共用设计文件，各自保留消息和草稿。关闭会话使用宿主归档接口，归档失败时保留会话并提示。

## 编辑与恢复

活动编辑器通过 SSE 接收文件变化，服务端每 1.5 秒核对已打开文件版本。编辑器自己的已提交版本不会被重复识别为外部修改。存在未保存输入时先保留输入并提示，保存仍校验源码版本。

插件内切换、关闭、重命名和归档会先等待编辑器完成保存和输入法处理。宿主直接离开设计页、外部移动文件或意外关闭等路径无法全部拦截；编辑器保留未确认保存输入的本机恢复记录，版本冲突时不自动覆盖文件。
