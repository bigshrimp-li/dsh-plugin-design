# Design 空间

Design 空间是 DeepSeek Harness 插件主面板。它复用原编辑器，并通过宿主的 `SessionProvider` 与 `conversation.content` 工厂嵌入对话。右侧栏编辑器继续保留。

## 使用步骤

1. 在插件目录执行 `npm run build`，然后完全退出并重启 Harness，使新增 Host 路由和客户端注册生效。
2. 点击左侧 `Design 空间`。在「设计区」添加空间根目录，展开后直接访问设计稿与关联对话。点击对话会打开对应设计稿及该会话。旧的目录根 `canvas.json` 继续兼容打开；新建其他设计稿需添加其上级目录为空间，避免嵌套破坏原稿校验。打开已有设计稿不会自动创建会话。
3. 点击 `＋` 或空间内「新建设计稿」。填写标题、目录名，选择设计空间和预设。支持空白、手机、网页、A4/A3 竖版；印刷预设只定义尺寸，导出仍是 HTML。
4. 选择新会话或空间内已有会话。新会话直接指定空间根目录为 cwd，不创建或注册宿主工作区，不创建会话文件夹。不填描述时只创建。新会话填写描述后按钮为「创建并发送」；已有会话只追加草稿，由用户核对后发送。
5. 拖动页签调整顺序，或聚焦页签后按 `Alt + 左/右方向键`。普通方向键切换页签。AI 对话位于画布右侧。左右拖动分隔条，或聚焦分隔条后按左右方向键调整宽度。右上角提供分栏、全屏、收起／打开对话侧栏三个图标，已移除「目录」「仅画布」「仅对话」按钮。
6. 点击右侧对话栏的「＋」可为当前设计稿新建独立会话，不自动发消息。点击会话页签切换；两个会话共用设计文件，各自保留消息、草稿和附件。悬停或键盘聚焦会话页签可看到「×」，点击后按工作区语义归档会话，可从宿主已归档列表恢复；设计文件不受影响。
7. 要回到完整对话，点击「在普通对话打开」。关闭设计稿页签只关闭界面，不停止宿主任务，不删除设计文件或关联会话。

## 侧栏分区

工作区与设计区相邻排列。点击标题或左侧箭头可分别收起、展开；两个区域互不影响，状态保存在本机，刷新后恢复。标题支持 Tab 聚焦和 Enter/空格操作。工作区收起时仍保留搜索和添加入口；聚焦搜索会自动展开列表。设计区标题右侧保留空间添加入口，使用与宿主「添加工作区」相同的文件夹加号图标；收起时也可添加空间。每个空间独立展开后列出设计稿及其对话，并提供在该空间新建设计稿的入口。

长列表在区域内滚动，账号菜单仍固定在底部。整体侧栏收起时保留宿主原有窄栏行为，展开后恢复两个区域的状态。

实现复用宿主工作区列表，不卸载列表，也不修改宿主包。由于当前 Harness 没有工作区标题扩展槽，插件对已核对的侧栏 DOM 结构添加受控标记和标题按钮。停用插件时清理标记；未来宿主结构不匹配时，回退到原工作区布局，设计区仍可独立折叠。升级 Harness 后需要复核这一兼容层。

## 状态与数据

- 同一真实路径在当前窗口只对应一个页签。最多打开 30 份设计稿。
- 同一设计稿可关联多个会话。旧的单会话关联自动保留，新建会话追加到列表，不替换旧会话。不同会话持有各自消息和草稿；显式关联同一会话时显示「共用这段对话」，共享历史和草稿。
- 打开的设计稿保留已访问会话的引用，默认只有活动设计稿的当前会话挂载对话输入区；分栏时挂载两个不同会话，每个会话仍只有一个输入框。后台页签不挂载隐藏输入框。宿主继续管理模型、附件、审批、停止和运行状态。
- 目录登记位于 `~/.dsh/design-space/directories.json`。最多登记 100 个根，兼容旧版隐藏扫描根；新版本只发现用户登记的设计空间，不再自动扫描或登记宿主工作区。重命名只改入口显示名称；移除只取消登记。
- 关联和创建操作标识位于设计空间根目录的 `.dsh/design-tabs.json`。`sessions` 保存每份设计稿的会话列表，原 `links` 字段保留默认会话以兼容旧数据；当前选中会话记录在本机 UI 存储。写入使用排他锁、版本检查、同目录临时文件替换，并保留 `.bak`。
- 创建的目录保留 `.dsh-creation.json` 操作凭据。若保存关联失败，可继续完成同一次创建；其他操作不能借同名目录覆盖文件。
- 页签顺序、活动页、当前会话、右侧栏宽度比例和未确认保存输入记录在本机 UI 存储。画布视口与已保存标注在当前插件运行期间按设计稿保留。
- 页面内最多同时运行 4 个缩略预览。预览独立于编辑器，不加载编辑桥。扫描最多递归 4 层、访问 800 个目录、返回 60 份设计稿。

## 空间、设计稿与产物的归属

每份新设计稿对应空间内的一个文件夹。画板源码、素材、说明与生成文件全部跟随设计稿；渲染 PNG 默认输出到 `<空间>/<设计稿>/.design-preview/`，离线 HTML 输出到其 `view/` 下，不再写到设计稿同级的公共目录。

新建表单使用「设计空间」选择器，优先记住当前空间，没有空间时要求先添加。创建后保留空间入口，不再把每个设计稿注册为新空间。设计区展开后按设计稿显示关联对话，可直接进入目标会话，名称随宿主更新，归档会话隐藏，恢复归档后重新出现。新增会话和分栏均使用空间 cwd，与宿主工作区列表无依赖。

旧目录第一次使用时升级为独立空间，将该目录对应的对话关联合并到本地 `.dsh/design-tabs.json`。旧关联文件与设计源码保持原样，已有旧 cwd 的绑定会话仍可访问；后续新会话使用空间根目录。不会移动旧版错误保存位置的设计文件，也不会删除已有宿主工作区。

空间内保存的是对话关联；会话历史、草稿和附件继续由 Harness 统一持久化，插件不复制或迁移宿主会话数据库。

## 外部修改与失败恢复

活动编辑器通过 SSE 接收变化。服务端每 1.5 秒核对已打开设计稿的文件内容版本，最多跟踪 60 份稿。只有存在 SSE 连接时执行核对；这是一种轮询对账，并非文件系统原生监听。编辑器自己的已提交版本会单独确认，避免被重复识别为外部修改。

Agent 或外部程序修改文件后，画布刷新，旧标注位置失效。已有未保存输入时先保留输入并提示；最终写入仍校验源码版本，不覆盖不同版本的文件。目录区元数据每 10 秒更新。

从 Design 空间切换、关闭或进入普通对话时，插件先等待保存和输入法完成。宿主侧栏直接离开、意外关闭等路径无法拦截；未确认保存的样式和文本会保留恢复记录。重新打开后可查看记录并按原版本恢复。若版本冲突，保留记录供用户复制和核对，不自动重放。

会话创建失败时保留已完成的设计文件，并显示「继续连接」。已有会话只追加描述，不自动提交。首次描述提交意图先消费，重挂载不再次发送；重启后尚未消费的描述只填入草稿，不自动发送。配置损坏或写锁未释放时提示原文件位置，不清空配置，也不删除他人的锁。

## 单行会话栏（2026-10-15）

对话区顶部合并为一行会话页签与「＋」，去掉「与 AI 的对话」、设计稿标签和数字序号。「在普通对话打开」保留为行末图标。当前空会话不额外占一个文字页签，默认只显示「＋」；已有的其他未命名会话用「＋」页签表示，悬停名称和无障碍名称可区分。关闭入口仍在悬停或键盘聚焦时显示。

名称与宿主工作区使用同一个会话目录：`blank` 为真时不显示名称，否则读取 `title.trim()`。插件不生成标题、不发额外模型请求。首轮对话后，宿主发布名称时立即显示；宿主后续重命名也同步更新。长名称截断，页签横向滚动，窄窗口不换成两行。

## 对话栏操作修复（2026-10-15）

新会话输入框置顶的原因是插件给 `conversation.content` 传了无效的 `phase: conversation`。宿主用 `phase: active` 启用消息流伸展与输入框底部吸附。现已改为 active，并仅在设计对话范围内为输入框容器补充自动顶部间距；空会话和长消息流都保持吸底。

右上角三个图标的行为：

1. 分栏：在右侧上下显示两个不同会话。已有第二会话时复用；只有一个会话时新建一个空会话，不自动发送。再次点击取消分栏。切换到另一栏正在显示的会话时交换两栏，避免同一会话挂载两个输入框。
2. 全屏：对话区占满设计主区域，再次点击恢复画布。分栏状态保留。
3. 收起／打开：收起时显示完整画布并卸载对话输入框，打开后恢复之前的对话布局与草稿。

会话关闭复用 `uiWorkspace.archiveSession`，不永久删除消息。已归档会话从设计会话列表隐藏，但关联记录保留，宿主恢复归档后可重新选择。关闭当前会话会切到剩余会话；关闭最后一个会话后显示连接入口。若宿主拒绝归档运行中的任务，保留会话并提示到工作区确认停止，插件不会直接终止任务。归档后保持设计页打开。
