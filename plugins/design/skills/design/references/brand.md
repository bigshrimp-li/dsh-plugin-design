# 品牌色与字体

用户说"用我们的品牌色"时该怎么做，以及**没有任何规范**时怎么定一套。

---

## 先找，别造

**已经有品牌资产的，一律不自己发明。**

按顺序找：

1. 工作区里有没有 `design-system.json` / `tokens.json`
2. 有没有 logo、品牌手册、已有的设计稿
3. 用户的网站、产品截图、宣传物料

找到了就**精确取色**（用取色器读实际值），不要"差不多是这个蓝"。

**没有找到、也没有规范时**：定一套，并且**明确告诉用户"这是我拟的，可以换"**。不要假装那是他们的品牌色。

**绝对不要**把 `[品牌色]` 之类的占位符留在最终稿里 —— 要么问到，要么给一个具体值并说明是拟定的。

---

## 定一套配色

### 结构

只需要三组：

```
一个强调色  +  一条中性阶（8–10 档）  +  三个语义色
```

**强调色**：主按钮、链接、选中态。**一屏只出现 1–3 次。**

**中性阶**：背景、文字、描边。占 90% 面积，决定界面"干净不干净"。

**语义色**：成功 / 警告 / 危险。**只在真有语义时用**，不要拿它们当装饰。

### 怎么推中性阶

不要用纯灰（`#808080` 那一路）—— 会显得死板。**让中性色带一点主色的色相**：

主色是蓝，中性色就偏冷；主色是橙，中性色就偏暖。做法是把主色**去饱和到 5%–15%**，再拉明度。

一条够用的中性阶（以冷灰为例）：

| 档 | 值 | 用途 |
|---|---|---|
| 50 | `#f9fafb` | 页面底 |
| 100 | `#f1f3f5` | 次级面板底 |
| 200 | `#e1e5ee` | **描边、分隔线** |
| 300 | `#cfd3d6` | 禁用描边 |
| 400 | `#adb2b8` | 占位文字 |
| 500 | `#979da6` | 弱化文字 |
| 600 | `#81858c` | 图标 |
| 700 | `#61666b` | **次要文字** |
| 900 | `#1b1b1c` | 标题 |
| 1000 | `#0f1115` | **正文**（别用纯黑） |

**深色主题不是把浅色反过来**：底色用接近黑的深灰（`#0f1115`），文字用接近白的浅灰（不是纯白），描边比底色亮一点点。强调色在深底上要**调亮**，否则会发闷。

### 验证对比度

定完必须验：

- 正文对背景 **≥ 4.5:1**
- 大字 / 图标 **≥ 3:1**
- 白字放在强调色上 **≥ 4.5:1**（很多品牌色**不达标**，这时要么加深色底，要么用深色文字）

算不准就查一下，别凭感觉。

## 定字体

### 规则

- **最多两个字体族**：一个标题、一个正文。一个也完全可以
- 没有特别理由时，**用系统字体栈**最快也最稳：
  ```
  system-ui, -apple-system, 'Segoe UI', 'PingFang SC', sans-serif
  ```
- **中文 + 西文混排**时，字体栈里把中文字体放后面，西文用前面的
- 等宽只给代码、ID、路径用

### 配对

要两个字体族时的安全组合：

| 标题 | 正文 | 适合 |
|---|---|---|
| 衬线（如 Georgia） | 无衬线 | 有质感、偏传统、印刷品 |
| 无衬线粗体 | 无衬线常规 | 现代、产品界面（**最稳**） |
| 几何无衬线 | 中性无衬线 | 偏科技、消费产品 |

**风险高的组合**：两个都很"有性格"的字体（会打架）；同一种字体的两个变体当两个族用（没必要）。

**离线注意**：在这套设计稿里引 Google Fonts，无网时会被替换成备用字体，**排版会变**。要稳定就导入本地字体，或者直接用系统字体。

---

## 定字阶

选一个**模数**，逐级乘上去：

- **1.2** —— 紧凑，适合信息密度高的界面
- **1.25** —— 通用，最常用
- **1.333** —— 舒展，适合营销页、海报

以正文 15、模数 1.25 为例：

```
15 → 18.75 → 23.4 → 29.3 → 36.6
取整：15  18  23  29  36
```

**定完就只用这几个值**，不要临时插一个 21。

印刷品可以跳到更大的模数（1.5），因为远看的层级需要拉得更开。

---

## 圆角与阴影

一起定，别一个元素一个样：

| | 值 |
|---|---|
| 小控件（标签、输入框） | 6–8 |
| 卡片、按钮 | 8–12 |
| 大面板、弹窗 | 12–16 |
| 胶囊 | 9999 |

**阴影表达层级，不是装饰**：

- 贴近背景的卡片：`0 1px 2px rgba(0,0,0,.06)`
- 浮起来的弹窗：`0 8px 24px rgba(0,0,0,.10)`
- **同一屏里阴影不超过两档**

---

## 写进哪里

- 只是这一份设计稿用 → 直接写在画板样式里
- 会被复用的品牌规范 → 建成设计系统（用 `design-system` 技能）

**建了设计系统就把取值都放进去**，别在设计稿里散落魔法数字。

## 自检清单

- [ ] 找过用户已有的品牌资产了吗？
- [ ] 颜色是取色来的，还是自己拟的？**拟的有没有说明？**
- [ ] 中性阶带一点主色色相，而不是纯灰？
- [ ] 强调色一屏出现 ≤ 3 次？
- [ ] 正文对比度 ≥ 4.5:1？
- [ ] 字体族 ≤ 2 个？
- [ ] 字阶选自同一个模数？
- [ ] 圆角和阴影各有固定档位？
- [ ] 有没有在稿子里留下 `[品牌色]` 这类占位符？**不该有**
