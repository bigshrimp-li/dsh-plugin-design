## 当前有效设计

- 综合空间群聊与 O 私聊使用不同派发策略，同一 Bot 的输入进入统一信箱。
- 每个 Bot 一个持久主会话，各任务具有可恢复子会话。主 Agent 用 task 工具分配，子 Agent 用 task.report 报告；不设独立分类或结算 Agent。
- 一个任务围绕连续目标、材料与交付组织。文章讲解、追问与基于讨论的笔记可连续；独立学习计划另建任务。已交付可续接，已结案后续新建关联任务。
- 主会话保留近期路由交谈与实际回答的必要片段，子会话保留自己的执行历史。SP/UP 稳定，段内追加，容量边界换段；阈值与缓存收益需评测。
- 单主会话可能见到本 O 混合来源路由记录，因此群派发仅允许授权引用，业务回答由来源隔离的子 Agent 生成；主 Agent 自由文本不直接广播到群。
- 记忆由当前任务 Agent 提交候选，Host 校验证据、作用范围和删除水位。业务事实仍回查正式记录。
- 保留支持判断、直接保存、缺项待整理、不支持不记录、草稿确认、历史原值、单独批量确认与归档规则。

- 旧工具修复读取范围、默认空间日期、坏O隔离、路径/符号链接、归档、歧义、周期拒写和真实回执。迁移与同进程旧写共享队列；迁移后旧JSON拒写，其他进程旧写须事先停止。
- 专用SQLite Worker实现检查备份、哈希迁移、统一事项、待整理、分类历史、精确统计、revision、幂等、行动/排期/分次执行、R/归档、原子批量变更、上下文fence及独立群库。
- 日历按明确时间范围投影daily/weekly/monthly（支持间隔、截止和次数）；每月保持原日号，短月缺此日则跳过。保留本地时钟并跨DST验证；未知旧规则和分页遗漏显式返回，不产生执行事实。
- 工具采用有界受限JSON程序，单命令最多一个业务写入；输入、scope、版本、回执和权限均由Host校验。trial只返回trial，不作为saved；试用范围拒绝更新、归档、执行等正式写入。CLI通过继承描述符交接凭据，HTTP凭据固定空间和方案版本。
- 方案从候选到真实试用、兼容性报告、用户确认、不可变文件和原子激活；真实试用选转/待整理可恢复。历史恢复生成新版本，批量修改单独预览确认。确认响应丢失可用原请求返回已提交版本，不重复激活。
- 当前不可变文件为manifest.json、bundle.json、types.json、page.json；bundle.json汇总CLI声明、受限程序和Skill，发现接口从同一版本读取，避免多份可独立修改的权威配置。
- Bot维护持久主/子映射、inbox/outbox、Host幂等键、lease/run/revision与source scope。默认同Bot最多两个不同子任务并行，同一子任务串行。每物理segment仅在DSH接纳后推进引用水位，后续只追加增量。稳定UP含用途和能力目录，不含全量事实、私聊记忆或动态数量。
- 资源驻留与业务阶段独立。取消、冷却、休眠、换段及记忆删除使用安全边界；旧上下文结果不能提交。逻辑Bot/task身份不变，物理session按context segment切换，以适配当前DSH不提供原地compact事件的实际能力。
- 综合群按授权原文offset派发；明确@固定接收者，查询/规划为只读建议授权，补充和结果回原群。同一事实不得多O保存，已接纳/已保存重试分别对账，方案操作停在草稿。
- 客户端移除initialData与setTimeout假回复，接真实记录、维度、行动、周期日历、待整理、试用、审查、方案历史、批量选择、R追评、记忆和群聊入口。模型不可用时真实关闭对应入口，不模拟成功。
