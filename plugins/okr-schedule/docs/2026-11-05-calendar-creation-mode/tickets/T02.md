# T02：接入 DSH 导航、返回与五档缩放

**状态：** 已完成　｜　**依赖：** 无，可直接开始

**PRD 依据：** [主页面：页面上的入口](../../../../../../learning/原型设计/目标日程插件/需求/2026-11-04-日程页与创造模式/主页面.md#页面上的入口)；[主页面：导航和窗口](../../../../../../learning/原型设计/目标日程插件/需求/2026-11-04-日程页与创造模式/主页面.md#导航和窗口)；[空间内：页面结构](../../../../../../learning/原型设计/目标日程插件/需求/2026-11-04-日程页与创造模式/空间内.md#页面结构)

把插件首页从现有工作台默认页切换到全局日历，并提供各业务页面共用的浅色外壳。此票验收页面切换、空间选择、尺寸变化与真实的宿主返回；日历内容和对话内容分别在后续票验收。

**改动入口：** [client.js](../../../client.js)、[index.js](../../../index.js)、[locale](../../../locale)、[browser.test.mjs](../../../test/browser.test.mjs)。

## 验收条件

- [x] 通过已登记的 DSH 插件入口进入默认月历；日程页、空间页和占满插件工作区的创造模式均有可见的「返回 DSH」。真正返回宿主后再次进入，先看日历，正式数据仍可用。保留现有包名、Loader ID 和 slot key。
- [x] 顶栏支持「日程」「空间」「创建空间」。「空间」打开本次使用的 O，首次取第一个；空间选择面板列名称、K 数和事项数，零空间提供创建入口。目标名称用于打开，复选框用于筛选。
- [x] 主背景明亮接近白色。80%、90%、100%、110%、125% 五档在 DSH 内容区缩放；窄窗保留日程、目标空间、多选面板、助手与删除入口，关键确认和返回按钮可达。
- [x] 宽窗主区与可收起的右栏并排；拖分隔线或聚焦后按左右方向键可调宽。空间不足自动收起，重开覆盖主区；窄窗切空间先收起。调宽和缩放不发消息、不写业务数据。

**验证方式：** 浏览器在宽窗和窄窗检查五档缩放、键盘调宽及焦点；用真实 DSH 入口核对进入、返回、重进，浏览器页内跳转不能替代宿主结果。

## 实施与验证

真实 DSH 0.2.1-rc.5 的隔离 Web profile 由根安装器安装。运行 `npm run test:host:browser`，从已登记侧栏进入默认月历，分别从日历、创造模式和已确认空间返回宿主；重进首屏仍为日历，可打开刚建的合成空间。实测五档比例、窄栏覆盖、键盘调宽与中文组词。浏览器另在 390 像素宽度从日历标题打开删除流程。
