# T03：恢复全局月、周、日历与多目标筛选

**状态：** 已完成　｜　**依赖：** [T01](T01.md)、[T02](T02.md)

**PRD 依据：** [主页面：查看某一天的日程](../../../../../../learning/原型设计/目标日程插件/需求/2026-11-04-日程页与创造模式/主页面.md#查看某一天的日程)；[总览：从 DSH 进入日程](../../../../../../learning/原型设计/目标日程插件/需求/2026-11-04-日程页与创造模式/产品设计.md#从-dsh-进入日程)；[助手：一轮回答怎样读到正确的数据](../../../../../../learning/原型设计/目标日程插件/需求/2026-11-04-日程页与创造模式/AI助手对话与数据读取.md#一轮回答怎样读到正确的数据)

用宿主的可见目标目录与各 O 正式排期渲染日历、图例和选中日清单。复用现有全局日历查询；勾选只作用于日历呈现，不修改 O，也不改变助手默认的读取范围。

**改动入口：** [client.js](../../../client.js)、[service.js](../../../src/host/service.js)、[domain.js](../../../src/host/domain.js)、[service.test.mjs](../../../test/service.test.mjs)。

## 验收条件

- [x] 首次进入为当地当月、已有 O 全选；按月、周一至周日、单日切换均保留选中日期与勾选。上一时段/下一时段按当前维度移动；「今天」和日期卡回到当地今天。
- [x] 月格最多直接列两项，多出的显示「+N 项」，点击进入当日日视图。周列标题也可进日视图；日/周时间线上重叠的两项均可打开，点击日期不会误开事件。
- [x] 多选、全选、清空及窄窗选择后，目标图例、目标数、当前视图事项数和按开始时间排序的当天安排同步更新。11 月 5 日只选英语显示 19:30 词汇复测，再选阅读增加 20:30 阅读与摘记。
- [x] 没有空间、没有勾选和已勾选但当天没有安排分别显示创建、勾选、可添加事项的入口。只显示正式排期；重复排期按发生日区分，部分 O 查询失败或分页不全不得冒充完整日历。

**验证方式：** 用合成日程覆盖跨月翻期、三项溢出、时间相交、多选、三种空态和读取部分失败；核对同一事项在视图切换前后的身份。

## 实施与验证

在插件目录运行 `node --test test/calendar.browser.mjs test/calendar-storage.test.mjs`。浏览器时钟固定到上海 2026-11-05。只选英语时看到 19:30 词汇复测，加选阅读后多出 20:30 阅读与摘记。第三件重叠事项使月格出现「+1 项」，进入日视图后可打开准确事项。月末翻页、周一至周日、今天、无勾选和零空间均走实际 UI。顶栏、目标栏、月历及助手宽度和横坐标与同宽原型对齐（误差小于 2 CSS 像素）。SQLite 用例另检验周期发生键、旧 JSON 的只读投影和单 O 失败。
