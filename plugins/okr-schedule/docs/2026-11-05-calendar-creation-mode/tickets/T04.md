# T04：在日历和空间共用事项表单与执行记录

**状态：** 已完成　｜　**依赖：** [T01](T01.md)、[T03](T03.md)

**PRD 依据：** [主页面：事项表单的字段与保存](../../../../../../learning/原型设计/目标日程插件/需求/2026-11-04-日程页与创造模式/主页面.md#事项表单的字段与保存)；[空间内：新增事项和记录执行结果](../../../../../../learning/原型设计/目标日程插件/需求/2026-11-04-日程页与创造模式/空间内.md#新增事项和记录执行结果)；[总览：每类操作何时保存](../../../../../../learning/原型设计/目标日程插件/需求/2026-11-04-日程页与创造模式/产品设计.md#每类操作何时保存)

交付一套可从日历或单空间打开的事项表单和详情。宿主保存一次，日历和空间读取同一事项；完成执行与阶段反馈 R 是两种操作。记账的附加字段由 T07 交付。

**改动入口：** [client.js](../../../client.js)、[domain.js](../../../src/host/domain.js)、[service.js](../../../src/host/service.js)、[service.test.mjs](../../../test/service.test.mjs)。

## 验收条件

- [x] 日历预填选中日期，优先选择一个已勾选 O，无勾选取一个可用 O，允许改选；空间入口锁定当前 O。默认 19:30、30 分钟、类型「实践」；没有空间引导创建。表单无需选择 K。
- [x] 名称必填且不超过 80 个字符，日期、时间有效，时长为 1 至 1440 分钟。错误保留输入并说明字段；关闭、遮罩或 Esc 放弃未保存编辑。
- [x] 「保存事项」成功才刷新。从日历添加时，选中日期切到该事项日期、所属 O 进入勾选范围。两个页面打开得到同一标识；空间默认筛选即使隐藏此项，日历仍可查到。
- [x] 详情显示 O、日期、星期、时间、时长、类型、状态和实际情况。「完成并保存」记录本次执行；「保存执行记录」修订已有结果，不重复创建事项或自动写 R/标记 K。可从详情打开所属空间。

**验证方式：** 从日历和锁定 O 的空间入口各建一项；核对 0/1/1440/1441 分钟边界、取消、一次执行及再次修订，刷新后用另一入口核对同一条记录。

## 实施与验证

通过 `test/calendar.browser.mjs` 在日历新增 1440 分钟事项，再从同一详情填写和修订执行。通过所属空间再新增 1 分钟事项，刷新日历后两个入口均能读回。0 和 1441 分钟就地提示，表单保留名称。Esc 退出后计数不变。执行修订后原事项恰有一条，K 保持原标记，R 保持原值。旧 JSON 投影支持只读详情，编辑沿用显式迁移入口。
