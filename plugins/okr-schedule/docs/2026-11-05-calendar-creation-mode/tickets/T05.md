# T05：固定展示 O、分组浏览 K 并手写唯一 R

**状态：** 已完成　｜　**依赖：** [T01](T01.md)、[T02](T02.md)

**PRD 依据：** [空间内：页面结构](../../../../../../learning/原型设计/目标日程插件/需求/2026-11-04-日程页与创造模式/空间内.md#页面结构)；[空间内：新增或修改过程目标 K](../../../../../../learning/原型设计/目标日程插件/需求/2026-11-04-日程页与创造模式/空间内.md#新增或修改过程目标-k)；[空间内：首次填写和修订阶段反馈 R](../../../../../../learning/原型设计/目标日程插件/需求/2026-11-04-日程页与创造模式/空间内.md#首次填写和修订阶段反馈-r)；[空间内：默认看待实现，历史从次要入口查看](../../../../../../learning/原型设计/目标日程插件/需求/2026-11-04-日程页与创造模式/空间内.md#默认看待实现历史从次要入口查看)

空间上方固定目标卡，每个 K 与自己的 R 在同一张卡里；宽窗并排、窄窗上下排列。增改 K 的入口去当前 O 的「调整目标」，本票负责正式空间的展示、手动状态和反馈编辑器。创造编辑与 AI 起草分别由 T11、T14 接入。

**改动入口：** [client.js](../../../client.js)、[domain.js](../../../src/host/domain.js)、[browser.test.mjs](../../../test/browser.test.mjs)。

## 验收条件

- [x] 进入空间默认看「待实现」，按截止日期升序；未来开始的标「未开始」，截止当天标「今天截止」。从当地次日起未手动实现的归「已过期」，最近过期在前；「已实现」按最近标记在前。两组历史用带数量的次要入口，三组互斥且各有空态。
- [x] 只有手动「标记已实现」才进入已实现，支持提前或过期后补标，记录标记日期；「撤销已实现」以当地当天重新归组，保留原 R。变更显示去向，翻日历、改筛选、写 R 不改变 K 的实现状态。
- [x] 当前组满 4 个 K 出现下拉定位，少于 4 个隐藏。滚轮、触摸、方向键、翻页键、Home/End 能在列表内定位完整 K/R；列表溢出给出数量、排序与滚动提示。
- [x] 「填写 / AI 起草」打开所选 K：空 R 显示待反馈，已有值可修订。只有非空正文和「确认保存反馈」能更新同一 R；关闭、仅起草均保留旧值。允许给过期 K 补反馈，保存后回原组与浏览位置。

**验证方式：** 固定本地时钟在截止日及次日；用 3 个、4 个及较多 K 的组验证下拉、滚动、分组、提前达标、撤销与同一 R 的首次保存和修订。

## 实施与验收结果

正式空间页面沿用原型的目标卡、成对 K/R 及带数量的历史入口。普通浏览只重算分组。手动标记、撤销和反馈修订分别提交到当前 O，并依据回执重新读取。

在插件目录运行 `node --test test/space-view.test.mjs` 核对 2026-11-05 截止与次日过期。运行 `OKR_BROWSER_TEST=1 node --test test/space.browser.mjs`，用临时 SQLite 与 Chrome 验证 5 → 4 → 3 个待实现 K 时下拉边界、键盘与下拉定位、今天截止与未来开始、提前实现和过期补标。两次保存后 R 标识一致，撤销实现和取消反馈编辑均保留原文。500px 窄窗实测 K/R 改为单列。宽窗实际截图已与「空间反馈-浅色预览.png」对照。
