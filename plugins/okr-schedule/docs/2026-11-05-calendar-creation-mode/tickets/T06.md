# T06：定制事项筛选、聚合和排版并保存空间默认

**状态：** 已完成　｜　**依赖：** [T01](T01.md)、[T02](T02.md)

**PRD 依据：** [空间内：自定义事项的筛选与聚合](../../../../../../learning/原型设计/目标日程插件/需求/2026-11-04-日程页与创造模式/空间内.md#自定义事项的筛选与聚合)；[空间内：从临时查看到保存为默认](../../../../../../learning/原型设计/目标日程插件/需求/2026-11-04-日程页与创造模式/空间内.md#从临时查看到保存为默认)；[空间内：视图控件的状态](../../../../../../learning/原型设计/目标日程插件/需求/2026-11-04-日程页与创造模式/空间内.md#视图控件的状态)；[空间内：用一周英语练习核对数字](../../../../../../learning/原型设计/目标日程插件/需求/2026-11-04-日程页与创造模式/空间内.md#用一周英语练习核对数字)

提供手工视图编辑器，以及供创造模式和空间助手复用的预览与统计逻辑。预览明确使用哪一批草稿或正式事项；数据筛选、统计规则与纯外观分别处理，固定 O/K/R 不参与排版。

**改动入口：** [client.js](../../../client.js)、[domain.js](../../../src/host/domain.js)、[scheme.js](../../../src/host/scheme.js)、[service.test.mjs](../../../test/service.test.mjs)。

## 验收条件

- [x] 默认全部事项按类型分组、统计条数。关键词匹配名称、类型、实际情况或实测结果；与本 O 的类型、状态、日期及适用时的收支方向取交集。日期支持全部、选中周、选中月、本周、本月、从今天起。
- [x] 支持不分组或按类型、日、周、自然月、状态分组；组内可算事项数、计划分钟、完成率（已完成数÷匹配数取整数百分比）。统计以全部匹配项为准，明细、小计和匹配数一致。零匹配显示空态。
- [x] 临时筛选即时生效。有条件才显示「清除筛选」；偏离默认且无待确认预览时出现「设为默认…」「恢复默认」。手改聚合先「预览当前空间」；放弃回到预览前，重新进入取本 O 保存的默认。
- [x] 「保存为默认」一次替换该 O 唯一一套筛选、分组、统计口径；零匹配亦可保存，相对时间下次按查看日期重算。不改变事项、R、全局日历或另一 O。
- [x] 列表/汇总卡、紧凑排列和首行突出执行结果可预览。纯样式用「应用排版」，不能顺带保存临时筛选；样式与规则一起改用「保存为默认」一起保存。预览中列出条件、分组、统计口径和匹配数，供确认前核对。

**验证方式：** 英语合成周有词汇练习 20、15、20 分钟，前两项完成：三项共 55 分钟、完成率 67%；只看已完成为两项 35 分钟。验证临时、放弃、仅排版及整套保存后重进。

## 实施与验收结果

空间正式页面和创造草稿共用 [筛选、汇总与排版](../../../src/client/space-view.js)。空间内的临时条件、待确认预览和 SQLite 内的已保存规则分开保存。仅改外观时，服务端只更新外观字段。

在插件目录运行 `node --test test/space-view.test.mjs`，核对选中周、本周、本月、从今天起、全部、状态与实测结果关键词，以及六种分组。运行 `OKR_BROWSER_TEST=1 node --test test/space.browser.mjs`，在真实页面核对三项 55 分钟、67%；筛已完成得两项 35 分钟。分别放弃预览、只应用卡片、保存整套规则，再将零匹配保存为默认并重新进入。读回 SQLite 后只应用卡片的默认状态仍为全部。
