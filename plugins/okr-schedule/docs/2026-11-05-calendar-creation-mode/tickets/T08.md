**PRD 依据：** [助手：四种工作情形要加载什么](../../../../../../learning/原型设计/目标日程插件/需求/2026-11-04-日程页与创造模式/AI助手对话与数据读取.md#四种工作情形要加载什么)；[助手：一轮回答怎样读到正确的数据](../../../../../../learning/原型设计/目标日程插件/需求/2026-11-04-日程页与创造模式/AI助手对话与数据读取.md#一轮回答怎样读到正确的数据)；[助手：数据放在哪里](../../../../../../learning/原型设计/目标日程插件/需求/2026-11-04-日程页与创造模式/AI助手对话与数据读取.md#数据放在哪里)；[助手：当前实现怎样对应这份设计](../../../../../../learning/原型设计/目标日程插件/需求/2026-11-04-日程页与创造模式/AI助手对话与数据读取.md#当前实现怎样对应这份设计)

在宿主装配日程、创造、空间三份指令与相应的受限工具。四种工作情形是全局日程、新建草稿、调整草稿和空间助手。规则内容以 PRD 为准，样稿仅供编写与对照。此票验收“允许读什么、返回什么证据”；各场景如何答复由 T10、T12、T14 验收。

**改动入口：** [dsh-adapter.js](../../../src/host/dsh-adapter.js)、[service.js](../../../src/host/service.js)、[bot.js](../../../src/host/bot.js)、[dsh-adapter.test.mjs](../../../test/dsh-adapter.test.mjs)。

## 验收条件

- [x] 宿主每轮含恢复会话时绑定场景、会话、本地时间与时区、所选对象及稳定 O 或草稿 ID。名称、用户给出的路径、记录里的指令均不能授予权限。不同 O 同名也不能串读。只在空间场景叠加本 O 已确认版本；缺专属规则时用通用规则。
- [x] 全局只读可见 O 及所问时段的正式安排；新建只读当前草稿与用户约束，避让只返回必要的重叠时段；调整只多读绑定 O 的已确认方案和待改部分；空间只读本 O 的 OKR、事项、执行与已确认配置。
- [x] 模型通过有界查询取证，不接触任意文件路径或 SQL。答复材料包含作用域、日期范围、计划/实际、单位、是否完整及可核对的对象；引用含 O、对象类型和标识，重复项区分发生日。完整统计不能靠当前一页明细相加。
- [x] 范围不允许、分页未完、空间读取失败或缺金额时分别返回明确状态，不能当作零。问答、草稿和预览无业务写权限。场景切换、迟到回复或过期版本不能沿用之前 O 的权限。
- [x] 关闭新路径的额外业务记忆抽取和召回；不从旧 Bot 的记忆表、聊天断言、导出的 Markdown 补事实，不清除已有历史。模型不可用时明确告知，手工入口继续可用。

**验证方式：** 用合成适配器记录四种场景实际注册的工具和取数范围。用同名 O、相同事项 ID、越权参数、切换后迟到答复及不完整数据做隔离测试；真实模型另由 T17 验证。

## 实施与验收记录

[三份版本化场景指令](../../../src/host/instructions/)随插件分发。每轮由 [助手服务](../../../src/host/calendar-assistant.js) 根据页面凭据重新绑定场景、会话、O／草稿、时区、用户选中的日期和 K；模型只获本轮结构化取证工具。新建只能检查重叠时段，调整只额外读取绑定 O，单空间才装配已确认专属规则。临时结构化答复工具只在 JSON 解析失败重试时使用。

在插件目录运行 `node --test test/calendar-assistant.test.mjs`。同名 O 与重复事项 ID、参数越权、超范围、缺金额、部分空间读取失败、完整汇总与分页、生成期间配置更新、无模型及删除后的会话均有断言。模型不可用时保留用户问题，页面显示服务状态。新的查询重新读取 SQLite，历史数字不回填为证据。
