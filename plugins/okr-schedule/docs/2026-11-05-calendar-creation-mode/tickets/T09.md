日程页和空间页复用侧栏交互，分别使用全局或当前 O 的会话。区分顶部会话选择、输入框的只读提问建议、单条答复的记录引用和预览入口。业务答案由各场景票提供。

**改动入口：** [client.js](../../../client.js)、[service.js](../../../src/host/service.js)、[bot.js](../../../src/host/bot.js)、[browser.test.mjs](../../../test/browser.test.mjs)。

## 验收条件

- [x] 标题显示「全局 · 全部目标」或「仅当前空间」加空间名。「＋」新建、下拉切换；新会话先有序号，首问开头用于命名。恢复实际消息和各自未发送文字，切换 O、收起或拉伸不串会话、不自动发消息或请求模型。
- [x] 空会话且输入为空时，根据已加载的页面数据给 0 至 2 条完整只读提问，无固定招呼语。打字即隐藏，空会话清空可再现；点建议等同主动发送，首轮后不再显示。无适用问题时只显示输入提示。
- [x] 按钮或 Enter 只发一次非空消息，Shift+Enter 换行；中文输入法选字时 Enter 先完成组词。读历史或打开侧栏不会生成多余问答或额外查日程。
- [x] 仅实际用到且可打开的事项或 K/R 放在对应答复之下；按 O、对象类型、对象标识和必要的发生日期去重，默认最多两条，其余可展开。点击复核权限，打开指定事项或 K/R，关闭回原会话；查看不发送也不写入。
- [x] 改视图只在发起变更的会话和答复下显示「查看事项区预览」；改长期规则带「在创造模式核对规则」。预览被替换或放弃后，旧入口失效。操作指引、空结果与纯排版不附无关事项。

**验证方式：** 用两全局会话、两个同名 O 和三条来源检查草稿恢复、中文输入、引用折叠与失效入口。记录打开侧栏和查看引用前后的发送数及业务写入数。

## 实施与验收记录

[侧栏组件](../../../src/client/assistant.js) 从 Host 恢复当前作用域的会话及输入。首次直接点「＋」保留会话 1 并打开会话 2。输入经 Host 确认前使用标签页临时缓冲，快速刷新可恢复最近一次输入，收到回执后清理临时缓冲。

在插件目录运行 `OKR_BROWSER_TEST=1 node --test test/assistant.browser.mjs`。Chrome 验证了建议点击单次发送、开始输入隐藏建议、中文组词 Enter、Shift+Enter、多会话切换、跨 O 输入隔离、三条引用默认显示两条及展开、打开详情、R 编辑器和规则差异。读历史、点击引用、放弃排版不会增加模型发送数。删除英语 O 后原合计收起，剩余阅读事项仍可打开。
