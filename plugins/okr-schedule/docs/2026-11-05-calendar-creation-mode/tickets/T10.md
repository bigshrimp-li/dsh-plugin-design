让全局日程助手回答安排、辨认所属目标，并把需要查看空间内执行事实或拟案的问题引向正确入口。复用 T08 的权限与 T09 的引用展示，不复用任何空间私聊。

**改动入口：** [service.js](../../../src/host/service.js)、[dsh-adapter.js](../../../src/host/dsh-adapter.js)、[client.js](../../../client.js)、[service.test.mjs](../../../test/service.test.mjs)。

## 验收条件

- [x] 有正式安排时可给「今天做什么」「查看本周安排」，选中非今天可改为「选中日有哪些安排」。无空间只给输入提示，由页面提供创建。用户发送后才按当地时间取数。
- [x] 默认按所有可见 O，只有明确「只看勾选的」才传日历勾选；点名 O 时解析稳定标识，同名让用户选择。本周取当地周一至周日，选中周取所选日期；本月、上/下月、指定年月及选中月分开计算。
- [x] 11 月 5 日日历只勾英语，问「今天做什么」仍返回英语、阅读两项；再问「只看勾选的」只剩英语。按日回答先报日期、数量和状态，名称与时间集中在可打开的引用行，能看出所属 O。
- [x] 问目标列表、建目标、查单空间执行/账目或删除时，分别给获准列表或进入空间、创造模式、页面删除流程的入口；全局会话不读取空间私聊或越权拿账目。结果为空与只读到部分 O 分开说明。

**验证方式：** 以 2026-11-05 的合成时钟执行两问和一次选中周追问，比较答案和引用的 O/事项 ID；另外模拟同名 O、空间读取失败和不可见空间。

## 实施与验收记录

[查询工具](../../../src/host/assistant-evidence.js) 将当地时间和所选日期分别换算为绝对区间。全局日程取可见目标的正式排期摘要，按问题选择当前勾选范围，对同名目标先返回待选标识。查询整组汇总与分页明细分别标明覆盖程度。

在插件目录运行 `node --test test/calendar-assistant.test.mjs` 及 `node scripts/calendar-model-probe.mjs`。临时 SQLite、真实安装的 DSH AgentLoop 和现有默认模型验证了 2026-11-05 的两问。只勾英语时首问仍引用英语和阅读，再问「只看勾选的」仅引用英语。选中周跨年、上月和闰年二月通过确定性断言。
