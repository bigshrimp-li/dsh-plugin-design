**PRD 依据：** [创造模式：两种入口](../../../../../../learning/原型设计/目标日程插件/需求/2026-11-04-日程页与创造模式/创造模式.md#两种入口)；[创造模式：首次输入与继续草稿](../../../../../../learning/原型设计/目标日程插件/需求/2026-11-04-日程页与创造模式/创造模式.md#首次输入与继续草稿)；[创造模式：预览中的编辑控件](../../../../../../learning/原型设计/目标日程插件/需求/2026-11-04-日程页与创造模式/创造模式.md#预览中的编辑控件)；[创造模式：确认前的检查和退出方式](../../../../../../learning/原型设计/目标日程插件/需求/2026-11-04-日程页与创造模式/创造模式.md#确认前的检查和退出方式)

交付创造模式的草稿界面与生命周期。新建用独立草稿标识；调整使用绑定 O 的已确认基线。对话和表单编辑同一版预览，不开新空间、不写正式计划。本票可用合成草稿独立验收；模型拟案、正式提交分别由 T12、T13 接手。

**改动入口：** [client.js](../../../client.js)、[scheme.js](../../../src/host/scheme.js)、[browser.test.mjs](../../../test/browser.test.mjs)。

## 验收条件

- [x] 顶栏新建与目标卡调整均占满插件工作区；宽窗并排显示对话与预览，窄窗可切换。「空间」「日程」页签核对同一份草稿。新建首条输入前预览为空、确认禁用；调整带入本 O 的 K/R、规则、布局和今天起尚待执行事项。
- [x] 仅新建、无输入且无对话时提供摄影、英语、记账示例；选择只填入可编辑文字，不发送、不生成。直接编辑或对话修订后，切页签能看到同一最新内容及修订顺序。
- [x] 可改 O 名称（必填、最多 40 字）与说明。新增 K 时名称与标准待填，起止日期默认从今天起四周，同时出现唯一待反馈 R；修改已有 K 的名称、标准或期限保留原 K 标识、R 和实现标记。当前生效的助手规则可与草稿逐字对照。
- [x] 日程预览可加、移除及修改拟排事项。新增项名称为空、类型「实践」、19:30、30 分钟；日期取上一项次日或空表时的明天。空间预览可改筛选、分组、统计和样式，记账另有方向和金额；只用草稿里可用的事项预览。
- [x] 关闭回原页，返回 DSH 后同入口也可续编，放弃会清掉本次草稿；只暂存一份。跨入口遇有已改内容给「取消 / 继续原草稿 / 放弃并切换」，前两项不丢原输入，纯空白可直接切换。

**验证方式：** 新建输入半句、选示例、编辑两页签、模拟对话后再改字段，分别经关闭、宿主返回及跨入口三种选择核对草稿；确认前查询正式记录始终不变。

## 实施与验收结果

[创造编辑器](../../../src/client/creator.js) 用稳定草稿 ID 暂存在当前工作区来源下。确认前，输入、对话和表单只更新这一份草稿。调整草稿保留 O/K/事项身份及启动时基线，重新打开可对照最新确认规则。

在插件目录运行 `OKR_BROWSER_TEST=1 node --test test/space.browser.mjs`。Chrome 中分别验证跨入口取消、继续、放弃，刷新后恢复，496px 窄窗两个面板的切换，以及三份示例只填入文字。核对新 K 四周期限、配对 R、新事项默认 19:30/30 分钟、连续与重叠时段、增加及移除行、手工编辑和合成模型交替修改。正式空间从 0 变为 1 只发生在按钮确认后。完成全部事项后还能单独更改已确认规则。真实模型和 DSH 导航分别见 T12、T17。
