# T16：从两个入口删除整个空间并清理失效来源

**状态：** 已完成　｜　**依赖：** [T05](T05.md)、[T09](T09.md)、[T10](T10.md)、[T11](T11.md)、[T15](T15.md)

**PRD 依据：** [主页面：删除一个空间](../../../../../../learning/原型设计/目标日程插件/需求/2026-11-04-日程页与创造模式/主页面.md#删除一个空间)；[空间内：空间资料与删除](../../../../../../learning/原型设计/目标日程插件/需求/2026-11-04-日程页与创造模式/空间内.md#空间资料与删除)；[总览：跨页面验收场景](../../../../../../learning/原型设计/目标日程插件/需求/2026-11-04-日程页与创造模式/产品设计.md#跨页面验收场景)

提供同一项按稳定 O 标识执行的删除，从日历或空间页发起。服务端清理、全局日历更新和历史会话引用处理必须一起验收。删除不是归档、清空筛选或重置演示。

**改动入口：** [client.js](../../../client.js)、[service.js](../../../src/host/service.js)、[domain.js](../../../src/host/domain.js)、[storage-worker.js](../../../src/host/storage-worker.js)、[storage.test.mjs](../../../test/storage.test.mjs)。

## 验收条件

- [x] 日历入口先空选，必须选择单个 O，同名显示标识尾码；空间入口锁定当前 O。两处均列名称、K/R 对数、事项数和空间会话数。多选勾选框不代表删除范围，取消无变化，聊天不能授权删除。
- [x] 只有「确认删除整个空间」才清除该 O 的整个独立目录（SQLite 及相关文件、两份 Markdown）、配置、历史及未来事项、空间会话及关联草稿，并移除全局索引。只清理所选 O；其他同名 O 和用户另行导出的文件保留。
- [x] 从空间删除后回日历，重新进入或刷新均不出现被删目标；最后一个 O 删除后仍有「创建空间」。失效草稿、迟到回复或重复请求不能重新建回被删 O。
- [x] 仅引用已删 O 的全局旧答复提示失效；跨空间旧答复收起旧合计并去掉该 O 引用，保留其他可核对引用，提示重新查。重问只计算现存可见空间，不能从旧聊天还原已删事实。
- [x] 删除失败明确说明哪些清理待重试，不能显示已完整删除；重试验证同一 O 的身份，不波及邻近目录。

**验证方式：** 只在临时数据根目录创建两个同名 O、各自的会话与导出副本；对两个入口测试取消、确认、最后一个空间、目录清理与混合来源答复。不触碰现用空间。

## 实施与验证

在插件目录运行 `node --test test/calendar-storage.test.mjs test/calendar-assistant.test.mjs`，浏览器分别重放 `test/calendar.browser.mjs` 和 `test/assistant.browser.mjs`。用两个同名 O 核对两个删除入口、取消、最后一个空间、跨空间旧合计失效与剩余引用。所有操作均使用合成空间。

清理之前记录目标 ID 和目录身份，确认成功才销毁数据。故意损坏临时全局索引，让删除在目录移动后中断，重新列目录仍得到同一 O 的待清理项。邻居符号链接替换被拒绝，修复索引后重试，其他空间与单独导出的副本仍可打开。已有 Worker 的迟到回复、旧确认草稿和重复请求均未复建空间。
