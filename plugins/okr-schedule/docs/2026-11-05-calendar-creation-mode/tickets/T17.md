## 验收条件

- [x] 跑完 PRD 五条跨页面场景：全局会话恢复/引用；已有调整草稿跨入口续回；截止当天手动实现与撤销；记账 120/150 元双口径；删除英语后跨空间合计失效且阅读来源仍可打开。留下可重现的前提、操作和观察值。
- [x] 走完建空间的完整闭环：说出英语目标→修改同一份草稿→暂离→按钮确认→打开新空间和全局首批日程→记录执行→起草并保存唯一 R→分别导出两个 Markdown。覆盖只改长期规则、只改排版、同时改视图和样式的不同保存边界。
- [x] 用浏览器和真实 DSH 工作区分别核对浅色、五档缩放、窄屏侧栏、键盘与中文输入、宿主返回及再次进入；用临时 HOME 核对 SQLite、Markdown、重启、旧空间兼容与硬删除。不得对用户实际业务数据做破坏性验证。
- [x] 用真实模型按全局、创造新建、创造调整、单空间分别验证取数、澄清、版本续接、跨 O 隔离及无按钮不写；真实模型不可用记为未验证。工程测试、合成模型传输、真实宿主和真实模型分别列结果。
- [x] 原型专用走查：五步标注开关、说明与跳转、创造三步提示、模拟宿主。默认日历、`#kr-demo` 与 `#ledger-demo` 分别存档，`#dsh` 与默认日历共用一份；重置先取消再确认，只影响当前演示档。正式插件中不应提供清空真实数据的「重置演示」。
- [x] 实施后的根检查/测试、插件浏览器与宿主检查均记录命令、环境、结果和剩余缺口。必要时核对发布包无样例用户数据；通过现有回归或离线原型不等于通过本票。

**验证方式：** 依次用临时数据验证领域与接口、浏览器验证页面、隔离 DSH 验证宿主和真实模型。命令和记录位置见本次 spec；本票在功能票交付后执行。
